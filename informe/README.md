# Informes (formato NeurIPS)

- Plantilla: Overleaf > New Project > Templates > "NeurIPS 2024" (o 2025).
  Usar `\usepackage[preprint]{neurips_2024}` para que aparezcan los autores.
- Una subcarpeta por pregunta (`p1_rodilla/`, `p2_inundaciones/`, `p3_fauna/`) con su `.tex`,
  `refs.bib` y una carpeta `figs/` donde se copian las figuras de `pX/reports/figuras`.
- Extensión orientativa: 6-10 páginas por informe más referencias.
- Las tablas y figuras de cada pregunta se generan en `pX/reports/` y se copian a `figs/`.
